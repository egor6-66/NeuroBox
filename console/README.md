<h2 id="главное">🏠 Главное</h2>

🖥️ Веб-пульт: разговоры, отправка реплик, ход прогона и его прерывание — то же, что умеет
сервис, но глазами и мышкой.

🔒 **Главное правило зоны: пульт не получает возможностей мимо API.** Всё, что он умеет, умеет и
[`neurobox/`](../neurobox/README.md) — иначе появится второй способ делать одно и то же, и они
разойдутся. Пульт потребитель, а не совладелец логики.

> [!NOTE]
> **Временный.** Сделан на рыночных пакетах, чтобы работать сегодня; когда выйдет фреймворк —
> будет переписан на нём. Поэтому здесь нет ни своей системы оформления, ни роутера: и то и
> другое пришлось бы выкинуть.

<h2 id="анатомия">🧩 Анатомия</h2>

📁 Раскладка послойная — то, что происходит, отделено от того, как это выглядит: переписать
оформление, не трогая поведение, должно быть возможно.

| Часть                     | Назначение                                                     |
| ------------------------- | --------------------------------------------------------------- |
| `app/main.tsx`            | точка входа                                                     |
| `pages/index.tsx`         | единственная страница: слева разговоры, справа текущий          |
| `widgets/chat`            | история, ход прогона, отправка и прерывание                     |
| `widgets/session-list`    | список разговоров                                               |
| `widgets/new-session`     | заведение разговора: рецепт, паспорт, агент                     |
| `entities/session/model`  | состояние разговора: подписка на события, отправка, отмена      |
| `shared/api/client`       | единственное место, знающее про HTTP                            |
| `shared/ui/styles.css`    | оформление; переменные вместо второй разметки под тёмную тему   |

<h2 id="использование">🚀 Использование</h2>

🐳 Поднимается вместе со всем остальным — `docker compose up`, пульт на
`http://127.0.0.1:3000`. Сервис он видит через себя же, поэтому открывать наружу порт API не
обязательно.

🧰 Разработка с быстрой обратной связью:

```bash
cd console
npm install
npm run dev        # :5173, запросы к сервису проксируются на :8000
npm run typecheck
```

<h2 id="ио">🔌 ИО</h2>

📥 На входе — HTTP-поверхность сервиса и его поток событий.
📤 На выходе ничего: пульт не источник данных, он их показывает и отправляет обратно тем же API.

🌐 **Один источник.** И в сборке, и в разработке запросы идут через `/api` того же адреса, что и
сама страница: в сборке проксирует nginx, в разработке — Vite. Так не нужны разрешения на чужие
источники, а поведение не расходится между режимами.

🚦 Отказ сервиса показывается его словами. Сервис объясняет отказы человеческим текстом, и
пересказывать их своими значило бы потерять то, ради чего они так написаны.
