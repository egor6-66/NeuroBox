<h2 id="главное">🏠 Главное</h2>

🐍 Сам сервис: HTTP-поверхность, агентский цикл, работа с базой. Всё, что умеет NeuroBox,
умеет этот скоуп — соседи вокруг него либо данные ([`config/`](../config/README.md)), либо
окружение ([`sidecar/`](../sidecar/README.md)), либо потребитель ([`console/`](../console/README.md)).

🪶 Держится тонким намеренно. Инструменты, браузеры и доменные знания сюда не приезжают — они
живут за MCP, а здесь только адрес и разговор по http. Всё, что тянет за собой окружение,
по определению чужая зона.

<h2 id="анатомия">🧩 Анатомия</h2>

📁 Раскладка `src/` — пакет лежит отдельной папкой, а не рядом с тестами и конфигами. Так тесты
гоняются против установленного пакета, а не против файлов на диске: расхождение между «работает у
меня» и «работает после установки» ловится сразу.

Что есть сейчас:

| Часть              | Назначение                                          |
| ------------------ | ---------------------------------------------------- |
| `main.py`          | точка входа: приложение и подключение маршрутов      |
| `api/main.py`      | сборка HTTP-поверхности — единственный список того, что сервис умеет |
| `api/routes/`      | сами маршруты, по файлу на тему                      |
| `core/config.py`   | настройки; заводятся вместе с кодом, который их читает |
| `model/`           | паспорта, семена, рецепты, склейка слоёв, сверка требований |
| `mcp/`             | опрос серверов и реестр того, что они дают            |

Что появится своими фазами (см. [`ROADMAP.yaml`](../ROADMAP.yaml) корня):

| Часть      | Назначение                                                        |
| ---------- | ------------------------------------------------------------------ |
| `worker`   | долгие прогоны агента вне обработчика запроса                      |
| `provider` | слой моделей — сегодня OpenAI, дальше локальные тем же контрактом   |
| `db`       | схема и миграции: сессии, история, владельцы, расход               |

<h2 id="использование">🚀 Использование</h2>

🐳 Единственный поддерживаемый способ запуска — `compose.yaml` в корне репозитория, см.
[Запуск](../README.md#запуск).

🧰 Прямой запуск существует только для быстрой обратной связи при разработке и ничего не обещает:

```bash
uv sync
uv run pytest
uv run ruff check .
uv run mypy src
```

🔒 Локфайл лежит в репозитории, и образ ставит зависимости с `--frozen`. Разошёлся с
`pyproject.toml` — сборка падает на этом месте, а не собирает молча что-то другое.

<h2 id="ио">🔌 ИО</h2>

📥 На входе — рецепт (комбинация семян), паспорт (чем думать) и сообщения сессии.
📤 На выходе — поток событий прогона и его результат, плюс расход, записанный в базу.

🚦 Отказ всегда возвращается **значением с именем**, а не исключением: сервер не поднялся, ключа
нет, лимит выбран, тулза отвергла. По имени пульт объясняет человеку, что случилось — разбор в
[корневом README](../README.md#базовые-понятия).
