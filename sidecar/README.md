<h2 id="главное">🏠 Главное</h2>

📦 Контейнер для MCP-серверов, которые говорят по `stdio` и приносят с собой окружение: node,
браузер, файлы чужих репозиториев. Здесь они поднимаются и оборачиваются в http, чтобы наружу
торчал один транспорт.

🎯 Смысл границы: **зоопарк заперт здесь**. [`neurobox/`](../neurobox/README.md) остаётся тонким и
одинаковым у всех, «поставить ещё один сервер» это правка одной папки, и упавший сервер не роняет
сессии. Это единственное место в репозитории, которое человек пересобирает под себя.

> [!WARNING]
> **Образа ещё нет.** Решение зафиксировано, работа — `mcp-sidecar` в
> [`ROADMAP.yaml`](../ROADMAP.yaml) корня.

| Часть        | Назначение                                                      |
| ------------ | ---------------------------------------------------------------- |
| `Dockerfile` | окружение серверов: node, браузер, что ещё нужно конкретным      |
| обёртка      | поднимает объявленные `stdio`-серверы и отдаёт их по http        |

<h2 id="использование">🚀 Использование</h2>

Серверы объявляются там же, где все остальные — в [`config/`](../config/README.md), обычной
`stdio`-записью с командой и аргументами. Сайдкар читает те же записи; для рантайма разницы между
таким сервером и внешним http-адресом нет.

➕ **Добавить сервер** — дописать запись в конфиг и, если он тянет новое окружение, дописать
`Dockerfile` здесь.

🚪 **Запасной выход.** Кому этой границы мало — собирает свой образ поверх базового. Это осознанный
выход, а не обход канона: он берёт на себя и вес образа, и его пересборку.

<h2 id="ио">🔌 ИО</h2>

📥 На входе — объявления `stdio`-серверов из конфига.
📤 На выходе — те же серверы по http, неотличимые для рантайма от внешних.

🚦 Сервер, который не поднялся, отдаётся именованным отказом наверх — молчаливого пропуска нет.
