<h2 id="главное">🏠 Главное</h2>

📁 Файловый слой конфигурации — **первый слой** из трёх (разбор слоёв — в
[корневом README](../README.md#слои)). Это твои личные стандарты: лежат в гите, ездят с тобой по
машинам, правятся руками и коммитятся как код.

✋ Не потроха сервиса, а данные для него. Поэтому отдельная папка: её содержимое человек открывает
и меняет постоянно, а [`neurobox/`](../neurobox/README.md) — почти никогда.

> [!WARNING]
> **Файлов ещё нет.** Форма файлового слоя — открытое решение, см. `file-layer-shape` в
> [`ROADMAP.yaml`](../ROADMAP.yaml) корня.

<h2 id="анатомия">🧩 Анатомия</h2>

> [!NOTE]
> Предложенная раскладка. Единый файл против раздельных — ещё не решено.

| Часть        | Что держит                                                      |
| ------------ | ---------------------------------------------------------------- |
| `mcp.json`   | реестр серверов: адреса, заголовки, команды `stdio`-серверов     |
| `passports/` | чем агент думает: провайдер, модель, лимиты, семплинг            |
| `seeds/`     | семена: адрес сервера или именованный кусок знания               |
| `recipes/`   | рецепты: комбинации семян                                        |

<h2 id="использование">🚀 Использование</h2>

Слой читается сервисом при старте. Элемент отсюда перекрывается одноимённым из базы — и наоборот,
элемент из базы можно перенести сюда осознанным экспортом. 🚫 Обратной автоматической записи нет:
сервис в эту папку не пишет никогда, иначе гит начал бы шуметь сам по себе.

<h2 id="ио">🔌 ИО</h2>

🔐 **Секреты сюда не кладутся.** Токены подставляются из окружения через `${VAR}`:

```json
{
  "mcpServers": {
    "windshift": {
      "type": "http",
      "url": "http://10.8.1.3:8095/mcp",
      "headers": { "Authorization": "Bearer ${WINDSHIFT_TOKEN}" }
    }
  }
}
```

Нет переменной — сервер не поднимается. Это заметная поломка, а не тихая: сервер, молча
пропущенный из-за отсутствия токена, выглядел бы как «агент почему-то не умеет».
