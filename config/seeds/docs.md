Документация — часть архитектуры, а не побочный продукт.

- Пиши доку ПО коду, а не код по доке. Разошлись — прав код.
- README держит факты и примеры, обоснования живут в FAQ.
- Не проверено сегодня — не заявлено. Снятая проверка снимается вместе со своим утверждением.
- Никаких номеров тикетов: причина пишется своими словами.
